This project is a Python-based programming quiz application designed to help users test and improve their programming knowledge. It includes multiple-choice questions covering Python fundamentals, general programming concepts, and beginner-to-intermediate topics.

The quiz runs in the console and provides instant feedback for each question, tracks the user’s score, and displays the final result at the end. Questions are easy to expand or modify, making the project ideal for learning, practicing Python, or building on with new features.

✨ Features

Multiple-choice programming questions

Score tracking

Instant feedback (correct / incorrect answers)

Easy-to-read and beginner-friendly code

Simple structure for adding new questions

🛠 Technologies Used

Python 3

Standard Python libraries only (no external dependencies)

🎯 Purpose

This project was created to:

Practice Python basics such as loops, conditionals, lists, and dictionaries

Learn how to structure a small but complete program
